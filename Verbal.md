# 1. SENTENCE COMPLETION

═══════════════════════════════════════════════════════════════

## THIS IS VERY HIGH ROI

Recent July 2026 candidate reports specifically mentioned
missing sentence-completion questions.

Current TCS NQT practice material also contains sentence/
passage completion questions.

───────────────────────────────────────────────────────────────

## BASIC PATTERN

```
The woman was ______
and brought down by an aerial ladder.
```

Options:

```
conscious
competing
flying
absent
```

Correct:

```
CONSCIOUS
```

The surrounding sentence tells you the meaning.

───────────────────────────────────────────────────────────────

## STEP 1 — READ WHOLE SENTENCE

DO NOT immediately look at options.

First ask:

```
What meaning is required?
```

───────────────────────────────────────────────────────────────

## STEP 2 — IDENTIFY PART OF SPEECH

Blank needs:

```
noun?
verb?
adjective?
adverb?
```

Example:

```
He is a ______ student.
```

Likely:

```
ADJECTIVE
```

Example:

```
He runs ______.
```

Likely:

```
ADVERB
```

───────────────────────────────────────────────────────────────

## STEP 3 — CHECK CONTEXT

Example:

```
The weather was extremely ______,
so the match was cancelled.
```

Possible:

```
pleasant
severe
beautiful
cheerful
```

Context:

```
match cancelled
```

Therefore:

```
SEVERE
```

───────────────────────────────────────────────────────────────

## STEP 4 — CHECK GRAMMAR

Example:

```
She ______ to college every day.

go
goes
going
gone
```

Subject:

```
She
```

Therefore:

```
GOES
```

───────────────────────────────────────────────────────────────

## STEP 5 — CHECK COLLOCATION

Some words naturally go together.

```
make a decision
```

NOT:

```
do a decision


heavy rain
```

NOT:

```
strong rain


take a break
```

NOT:

```
make a break
```

This can eliminate options quickly.

───────────────────────────────────────────────────────────────

## MASTER METHOD

```
SENTENCE
   ↓
MEANING
   ↓
PART OF SPEECH
   ↓
GRAMMAR
   ↓
WORD COMPATIBILITY
   ↓
ANSWER
```

```

```

```

```

RESULT → consequence
```

# 3. ERROR DETECTION

═══════════════════════════════════════════════════════════════

## MOST IMPORTANT GRAMMAR RULES

Don't learn 50 grammar rules tonight.

Master these.

───────────────────────────────────────────────────────────────

# SUBJECT–VERB AGREEMENT

Singular:

```
He goes.
```

Plural:

```
They go.
```

WRONG:

```
He go to college.
```

RIGHT:

```
He goes to college.
```

───────────────────────────────────────────────────────────────

## TRAP

Words between subject and verb
do NOT change the subject.

```
The boy,
along with his friends,
is playing.
```

Subject:

```
boy
```

Therefore:

```
IS
```

───────────────────────────────────────────────────────────────

# EACH / EVERY

Usually singular verb:

```
Each student is ready.

Every boy has a book.
```

───────────────────────────────────────────────────────────────

# ONE OF

```
One of the boys is absent.
```

NOT:

```
One of the boys are absent.
```

───────────────────────────────────────────────────────────────

# EITHER / NEITHER

Usually singular:

```
Neither answer is correct.

Either option is acceptable.
```

───────────────────────────────────────────────────────────────

# TENSE

Past:

```
He went.
```

Present:

```
He goes.
```

Continuous:

```
He is going.
```

Perfect:

```
He has gone.
```

───────────────────────────────────────────────────────────────

## TIME CLUES

```
yesterday
   ↓
PAST


every day
   ↓
PRESENT


since
   ↓
often PERFECT / continuing state


already
   ↓
often PERFECT


tomorrow
   ↓
FUTURE
```

```

```

Before vowel SOUND:

```

```

```

```

───────────────────────────────────────────────────────────────

## THE

Specific / already identified:

```
the book on the table
```

Unique:

```
the sun
```

Superlative:

```
the best
```

Ordinal:

```
the first
```

───────────────────────────────────────────────────────────────

## BIG TRAP

Don't judge by LETTER.

Judge by:

```
SOUND


a university

an umbrella

an honest man
```

# 10. READING COMPREHENSION

═══════════════════════════════════════════════════════════════

## FIRST RULE

DON'T PANIC WHEN YOU SEE A LONG PASSAGE.

───────────────────────────────────────────────────────────────

## STEP 1

Look at:

```
QUESTIONS
```

before deeply reading the passage.

───────────────────────────────────────────────────────────────

## STEP 2

Read passage for:

```
MAIN IDEA
STRUCTURE
KEY FACTS
```

───────────────────────────────────────────────────────────────

## STEP 3

When question asks:

```
"According to the passage..."
```

Answer:

```
PASSAGE FACT
```

NOT:

```
YOUR OWN KNOWLEDGE
```

───────────────────────────────────────────────────────────────

# QUESTION TYPE 1 — MAIN IDEA

Question:

```
What is the passage mainly about?
```

Look for:

```
central theme
```

Not:

```
one small detail
```

───────────────────────────────────────────────────────────────

# QUESTION TYPE 2 — DIRECT FACT

Question:

```
According to the passage...
```

Find exact location.

Answer directly.

───────────────────────────────────────────────────────────────

# QUESTION TYPE 3 — INFERENCE

Question:

```
It can be inferred that...
```

Answer must be:

```
logically supported
```

NOT:

```
explicitly stated necessarily
```

───────────────────────────────────────────────────────────────

# QUESTION TYPE 4 — WORD IN CONTEXT

Question:

```
"X" most nearly means...
```

Look at:

```
surrounding sentence
```

───────────────────────────────────────────────────────────────

# QUESTION TYPE 5 — AUTHOR'S TONE

Common:

```
positive
negative
neutral
critical
optimistic
skeptical
```

───────────────────────────────────────────────────────────────

## MASTER RC METHOD

```
QUESTION
   ↓
KEYWORD
   ↓
LOCATE
   ↓
READ SURROUNDING SENTENCE
   ↓
ANSWER FROM PASSAGE
```

───────────────────────────────────────────────────────────────

Opening sentence usually:

```

```

```

```

```
"Therefore..."
```

If sentence says:

```

```

```

```

therefore
moreover
additionally
consequently
then
finally

───────────────────────────────────────────────────────────────

## STEP 4 — CHRONOLOGY

Look for:

```

then
later
finally
```

───────────────────────────────────────────────────────────────

## MASTER STORY

   ↓

   ↓

```

```

```

```

```
A → B
```

```
A describes problem.

B says "therefore".
```

Therefore:

```
A → B
```

## MASTER LINK WORDS

```

that
these
those
he

they
it

# 14. ACTIVE / PASSIVE

═══════════════════════════════════════════════════════════════

## ACTIVE

```
Ram wrote the letter.
```

Subject:

```
Ram
```

Action:

```
wrote
```

Object:

```
letter
```

───────────────────────────────────────────────────────────────

## PASSIVE

```
The letter was written by Ram.
```

Object becomes subject.

───────────────────────────────────────────────────────────────

## BASIC TRANSFORMATION

```
Active:
Subject + Verb + Object


Passive:
Object + be + V3 + by + Subject
```

───────────────────────────────────────────────────────────────

## EXAMPLE

```
They completed the work.

    ↓

The work was completed by them.
```
