# 6. SYLLOGISM

═══════════════════════════════════════════════════════════════

## CORE IDEA

Statements:

```

Some B are C.
```

Question:

```
Which conclusion follows?
```

───────────────────────────────────────────────────────────────

## VISUAL METHOD

"All A are B"

means:

```
   B
┌─────────┐
│   A     │
│ ┌─────┐ │
│ │     │ │
│ └─────┘ │
└─────────┘
```

───────────────────────────────────────────────────────────────

## "NO A IS B"

A and B:

```
DISJOINT


┌───┐       ┌───┐
│ A │       │ B │
└───┘       └───┘
```

───────────────────────────────────────────────────────────────

## "SOME A ARE B"

There is an overlap.

```
    A
   ┌───┐
   │ ┌─┼──┐
   │ │X│  │
   └─┼─┘  │
     └────┘
       B
```

───────────────────────────────────────────────────────────────

## CRITICAL RULE

```
ALL A ARE B
```

does NOT mean:

```
ALL B ARE A
```

───────────────────────────────────────────────────────────────

## ANOTHER TRAP

```
SOME A ARE B
```

does NOT imply:

```
SOME A ARE NOT B
```

───────────────────────────────────────────────────────────────

## MASTER

```
Convert sentences
   ↓

   ↓
Test conclusion
```

───────────────────────────────────────────────────────────────

## RECOGNITION

# 10. DATA SUFFICIENCY

═══════════════════════════════════════════════════════════════

## MOST IMPORTANT IDEA

You are NOT necessarily solving the problem.

You are asking:

```
"Is the information sufficient?"
```

───────────────────────────────────────────────────────────────

## TYPICAL FORMAT

Question:

```
What is x?
```

Statement I:

```
...
```

Statement II:

```
...
```

Determine:

```
I alone sufficient?

II alone sufficient?

Both together?

Neither?
```

───────────────────────────────────────────────────────────────

## MASTER METHOD

Test:

```
Statement I ONLY
```

If answer uniquely determined:

```
I sufficient
```

Then:

```
Statement II ONLY
```

If neither:

```
combine I + II
```

───────────────────────────────────────────────────────────────

## CRITICAL TRAP

Don't assume:

```
more information
   =
automatically sufficient.
```

Check whether:

```
UNIQUE ANSWER
```

is possible.

# 12. STATEMENT & ASSUMPTION

for the statement/proposal to make sense.

───────────────────────────────────────────────────────────────

## TEST

Ask:

```
"Does the statement depend on this
 idea being true?"
```

```
assumption likely present.
```

───────────────────────────────────────────────────────────────

## EXAM TRICK

Don't confuse:

```
conclusion
```

with:

```
assumption.
```

Conclusion:

```
what follows.
```

Assumption:

```
what is taken for granted.
```
